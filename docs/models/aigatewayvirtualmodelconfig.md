# AiGatewayVirtualModelConfig

Public response shape for virtual model configs. Used so OpenAPI generation can avoid ElectroDB's recursive EntityItem types.

## Example Usage

```typescript
import { AiGatewayVirtualModelConfig } from "@vercel/sdk/models/aigatewayvirtualmodelconfig.js";

let value: AiGatewayVirtualModelConfig = {
  createdAt: 9240.95,
  deleted: false,
  kind: "<value>",
  ownerId: "<id>",
  status: "<value>",
  updatedAt: 5306.71,
  virtualModelSlug: "<value>",
};
```
