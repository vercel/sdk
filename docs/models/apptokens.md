# AppTokens

App-token capabilities and known grants for the connector.

## Example Usage

```typescript
import { AppTokens } from "@vercel/sdk/models/connectconnector.js";

let value: AppTokens = {
  crossInstallation: false,
  supportsRefinement: true,
};
```
