# GetAllLogDrainsDrainsDeliveryStats

Delivery health of a drain over the last 24 hours, counted on finished deliveries (a delivery saved by an automatic retry counts once, as delivered): `failing` when more than 5 deliveries failed and they are at least 1% of all finished deliveries, `healthy` otherwise, and `unknown` when no delivery finished in the window.

## Example Usage

```typescript
import { GetAllLogDrainsDrainsDeliveryStats } from "@vercel/sdk/models/getalllogdrainsop.js";

let value: GetAllLogDrainsDrainsDeliveryStats = {
  attempts: 8500.62,
  failures: 6122.63,
  state: "unknown",
  totalFailedDeliveries: 5586.08,
  totalRetriedDeliveries: 8764.21,
  totalSuccessfulDeliveries: 9863.07,
  window: "24h",
};
```
