# Models2

A conditional fallback. Only an alias can have one.

## Example Usage

```typescript
import { Models2 } from "@vercel/sdk/models/createaigatewayvirtualmodelconfigop.js";

let value: Models2 = {
  model: "PT Cruiser",
  when: {},
};
```
