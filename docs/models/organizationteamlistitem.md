# OrganizationTeamListItem

An org-team link enriched with the linked team's display fields, as returned by the list-teams endpoint. We project to an explicit flat interface instead of spreading the ElectroDB `OrganizationTeamItem` because its recursive generics break the OpenAPI generator (which would silently drop the route).

## Example Usage

```typescript
import { OrganizationTeamListItem } from "@vercel/sdk/models/organizationteamlistitem.js";

let value: OrganizationTeamListItem = {
  avatar: "https://loremflickr.com/1035/1727?lock=1470969127589683",
  createdAt: "1722777906616",
  name: "<value>",
  organizationId: "<id>",
  slug: "<value>",
  ssoMode: "team",
  teamId: "<id>",
  updatedAt: "1735689540853",
};
```
