# PayloadHistory

History of MFA state changes (enabled/disabled events). Most recent events first.

## Example Usage

```typescript
import { PayloadHistory } from "@vercel/sdk/models/lasteditedbyprincipal.js";

let value: PayloadHistory = {
  action: "disabled",
  actorId: "<id>",
  actorType: "admin",
  method: "user_disabled",
  timestamp: 1898.83,
};
```
