# PayloadHobbyAllocationPause

Present only when `reason` is `HOBBY_ALLOCATION_PAUSED`. Makes the pause self-describing for support without a separate lookup.

## Example Usage

```typescript
import { PayloadHobbyAllocationPause } from "@vercel/sdk/models/postgres2.js";

let value: PayloadHobbyAllocationPause = {
  pausedUntil: 7931.58,
  pausedAt: 3093.83,
  triggers: [],
  cohort: "<value>",
};
```
