# ServerConfig

Authorization server metadata. Values override discovered metadata. Empty known string fields remove their stored overrides.

## Example Usage

```typescript
import { ServerConfig } from "@vercel/sdk/models/connectconnectorcreatedata.js";

let value: ServerConfig = {};
```
