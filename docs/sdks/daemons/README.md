# Daemons

## Overview

### Available Operations

* [getProjectBoxes](#getprojectboxes) - Get project daemons
* [putProjectDaemonInstances](#putprojectdaemoninstances) - Override a project daemon's instance counts
* [restartProjectDaemonInstance](#restartprojectdaemoninstance) - Force restart a project daemon instance
