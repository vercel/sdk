# Drives

## Overview

### Available Operations

* [listDrivesV1](#listdrivesv1) - List drives
* [getDriveV1](#getdrivev1) - Get a drive
* [getOrCreateDriveV1](#getorcreatedrivev1) - Get or create a drive
* [deleteDriveV1](#deletedrivev1) - Delete a drive
* [forkDriveV1](#forkdrivev1) - Fork a drive

## listDrivesV1

Retrieves a paginated list of drives belonging to a specific project.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="listDrivesV1" method="get" path="/v1/drives" -->
```typescript
import { Vercel } from "@vercel/sdk";

const vercel = new Vercel({
  bearerToken: "<YOUR_BEARER_TOKEN_HERE>",
});

async function run() {
  const result = await vercel.drives.listDrivesV1({
    projectId: "prj_abc123",
    teamId: "team_1a2b3c4d5e6f7g8h9i0j1k2l",
    slug: "my-team-url-slug",
  });

  console.log(result);
}

run();
```
